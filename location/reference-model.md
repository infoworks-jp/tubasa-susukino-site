400m四方・遠景なし・人と車なし・平坦。真上のカメラから正規GLB書き出し。参考モデルの道路・建物・街路樹を利用。表示上は建物283棟、高さ推測168棟、道52、木667。参考の生成外観は窓・店先・看板・屋上設備まで細かいが、現地を写真測量したモデルではない。

初回の起伏ありのモデルでは地表の最大標高が相対151mに達し、道路にも同様の異常があった。地形を平らにして再書き出しし、平坦な道路・地表を確認した。標高の精密再現とは表示しない。

制作時の元GLBは112,129,536 bytes。glTF Transform CLI 4.2.1 の weld → quantize → meshopt → instance → prune（未使用UV削除）→ meshopt を使用。近景は同じ形状の頂点・樹木を共有して圧縮し、ポリゴン削減を使わない。表示用の遠景樹木だけ別モデルを用意し、meshoptimizerによる目標10%・半径比の最大誤差1.5%の簡略化を行う。近くは高精細モデル（250万頂点まで）、遠くは簡略モデルへ切り替える。GLB保存は高精細の形状を復元して行う。最終ファイルはEXT_meshopt_compression、KHR_mesh_quantization、EXT_mesh_gpu_instancingを使用。Three.js同梱のMIT decoderで復号する。

入口の写真はユーザーが自分で撮影／利用許可ありと確認。看板などの四隅のピクセル座標はphoto-facade.mjsで公開。横丁看板198pxを3.2m、路面のY575pxを基準とする共通座標で、相対比率を保持する。絶対寸法と屋内区画は測量していない。生成モデルの樹木が入口を覆う部分は写真の証拠を優先し、除外する。

閲覧時の外部API呼び出しはなく、GLB、写真、プログラムは同一サイトから静的配信。生成された窓・看板・屋上設備を実物の確認済み外観とは扱わない。
